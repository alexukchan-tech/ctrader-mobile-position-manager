# cTrader Mobile Position Manager 6.0 Read-Only Release

Version 6.0 consolidates the working Plugin SDK connection, execution-event ledger, session restoration, event-tracked position and pending-order lists, symbol-name mapping, live bid/ask display, quote freshness, estimated tracked P/L, lifecycle filtering, compact diagnostics, validation summary, and close-position simulation.

The portfolio view remains partial because positions and orders that existed before the plugin connected may be missing. Therefore, Version 6.0 intentionally contains no live close, partial-close, breakeven, cancel-order, modify-order, or batch-trading capability.
